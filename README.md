# Plow Smoke Test

The smallest agent that can be built on [plow-openclaw-agent](https://github.com/plow-pbc/plow-openclaw-agent):
the base image, plus the Agent Index identity that a cloud install needs.

It exists to prove the path end to end — a 1-click install answers its owner and
its usage reaches [the Agent Index](https://aiworthusing.com/agent-index/plow-smoke-test) —
so builders hit a path that has been walked.
